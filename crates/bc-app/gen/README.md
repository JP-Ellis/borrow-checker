# `gen/` — Tauri-generated artefacts

Files here are generated by `tauri_build::build()` (called from `build.rs`) during
a normal `cargo build`. They are committed so that IDEs and editors can provide
schema completion for the `capabilities/` directory without needing a prior build.

## Files

| File | Purpose |
|------|---------|
| `schemas/acl-manifests.json` | ACL permission manifests for every bundled Tauri plugin |
| `schemas/capabilities.json` | JSON Schema for files under `capabilities/` |
| `schemas/desktop-schema.json` | Desktop-specific `tauri.conf.*` JSON Schema |
| `schemas/macOS-schema.json` | macOS-specific `tauri.conf.*` JSON Schema |

## Regenerating

Run any build that invokes `build.rs`:

```sh
cargo build -p bc-app
```

The files are deterministic for a given Tauri version, so they only change when
the Tauri dependency is updated.
