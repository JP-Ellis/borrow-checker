# CLAUDE.md

This file provides guidance to AI agents when working with code in this repository.

## Target

`bc-ui` compiles **only** to `wasm32-unknown-unknown`. Always lint and check against that target:

```sh
cargo clippy -p bc-ui --target wasm32-unknown-unknown -- -D warnings
```

A native `cargo check` will not catch missing `web-sys`/`js-sys` features or WASM-only APIs.

## Stack

- **Leptos 0.8** (CSR) — reactive UI framework
- **leptos_router 0.8** — client-side routing
- **Stylance 0.8** — CSS modules (`.module.scss` files compiled to scoped class names)
- **Tauri-sys** — bridge to Tauri IPC commands from WASM
- **web-sys / js-sys** — DOM and JS APIs

## Architecture

```text
src/
  main.rs          # CSR entry point; mounts <App/>
  app.rs           # Router: ParentRoute(ConsoleShell) wraps all page routes
  shell.rs         # ConsoleShell layout (sidebar nav, top bar)
  components/      # Design-system atoms — reusable across all pages
  pages/           # One subdirectory per route
    __test/        # Debug-only QA showcase routes (cfg(debug_assertions))
style/             # Global SCSS + Stylance bundle output (NOT inside src/)
  main.scss        # Global stylesheet entry point (tokens, reset, shell)
  bundle.scss      # Generated by Stylance — gitignored, do not edit
  tokens/          # SCSS-only variables (breakpoints, etc.)
  mixins/          # SCSS mixins (focus ring, etc.)
  base/            # Reset and root rules
  shell/           # Shell layout SCSS
  utilities/       # Utility classes
```

**Pages own their sub-components.** A page like `accounts/` contains its own `components/` subfolder for things that are specific to that page. Only promote a component to the top-level `components/` when it is genuinely reused across pages.

## File Colocation Rule

Every component lives in its own directory with exactly these co-located files:

```text
transaction_row/
  mod.rs              # Component definition
  row.module.scss     # Scoped styles (imported via import_style!)
  qa.rs               # QA showcase page (cfg(debug_assertions) only)
```

- `import_style!(style, "row.module.scss")` loads the CSS module as a Rust struct.
- Access class names as `style::class_name`.
- Never use string literals for class names.

## Design Tokens

All visual values come from CSS custom properties defined in `style/tokens/`. Never hardcode colours, spacing, radii, or font sizes — use the tokens.

**Colour** (`--bc-*`): OKLCH palette with light/dark theme support. Derived tokens are computed via `color-mix()` and update automatically when the base changes. Key semantics:

| Token | Meaning |
| ------------------------------------------------------------------------------------ | ------------------------------ |
| `--bc-bg` / `--bc-ink` | Page background / default text |
| `--bc-surface` / `--bc-surface-alt` / `--bc-surface-accent` | Elevation layers (low → high) |
| `--bc-accent` | Primary interactive colour |
| `--bc-good` / `--bc-bad` / `--bc-warn` | Semantic status |
| `--bc-border` / `--bc-border-strong` | Separator lines |
| `--bc-ink-soft` / `--bc-ink-mute` / `--bc-ink-dim` | De-emphasised text |
| `--bc-keyword`, `--bc-string`, `--bc-number`, `--bc-type`, `--bc-fn`, `--bc-comment` | Syntax highlighting |

**Spacing** (`--bc-space-1` … `--bc-space-9`): 4 px base scale. Use these everywhere — no arbitrary `px` values.

**Typography**: `--bc-font-mono` (Fira Code), `--bc-font-sans` (Inter Tight). Type scale via `--bc-text-eyebrow`, `--bc-text-caption`, `--bc-text-body`, etc.

**Radius**: `--bc-radius-tag`, `-kbd`, `-tab`, `-control`, `-card`, `-pill`.

**Motion**: `--bc-duration-fast`, `-normal`, `-slow` + `--bc-ease-out`.

## SCSS Conventions

- Use `/* */` block comments, not `//`. Single-line comments are not supported by the SCSS toolchain in use.
- Nest `@media` queries inside the rule they affect — do not separate them into a media block at the bottom.
- Use `@layer` cascade layers (order: `tokens → base → shell → utilities`). Component module files are outside the layer system and take precedence naturally.

### Stylance and `@use`

**Never add `@use` to individual `.module.scss` files.** Shared imports are declared once in `scss_prelude` in `Cargo.toml` and are available to all module files. Adding `@use` to a module file will break the SCSS compilation of `style/bundle.scss`.

SCSS variables from `@use` resolve correctly in `@media` conditions but **not** in bare `@container` conditions. Use `#{}` interpolation: `@container (min-width: #{bp.$bp-md})` instead of `@container (min-width: bp.$bp-md)`.

## Component Patterns

**Responsive grids**: Change `grid-template-columns` inside nested `@media` breakpoints. Hide cells at narrow widths with `display: none` at the same breakpoints, keeping headers and rows in sync. Use `auto` for content-driven column widths (e.g. amounts) so they never overflow into adjacent cells; use `fr` units for proportional columns.

**Reactive state**: Use `RwSignal` for local mutable state, `Signal::derive` for computed values, `Memo` when derivation is expensive. Pass `ReadSignal` / `Signal` to children — not `RwSignal` — to enforce single-writer ownership.

**Props**: Use `#[prop(into)]` for `String` props (accept `&str` at call sites). Use `#[prop(optional)]` and `#[prop(default)]` rather than `Option<T>` where a sensible default exists.

**Callbacks**: Use `Callback<T>` for event handlers passed down from parents. Call with `.run(value)`.

**`#[expect]` over `#[allow]`**: Clippy suppression always requires `reason = "..."`. Common legitimate suppressions in this crate:

- `clippy::needless_pass_by_value` on component functions (Leptos props require owned types)
- `clippy::too_many_lines` on components with large `view!` blocks
- `clippy::absolute_paths` where `leptos_router::path!` macro expansions emit them

## QA Routes

Every component should have a `qa.rs` that renders a self-contained showcase — different states, edge cases, size variations. QA routes are registered under `/__test/*` and are compiled out in release builds. This is the primary way to visually verify components without running the full app.

## Formatting

Run both formatters — rustfmt alone is not enough for Leptos:

```sh
cargo +nightly fmt
leptosfmt crates/bc-ui/
```
